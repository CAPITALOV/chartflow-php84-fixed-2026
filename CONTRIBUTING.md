# Contributing

Репозиторий ведётся индивидуально; изменения публикуются в ветку `main`.
При добавлении кода:

1. Не коммитьте файлы с секретами (`config/db.php`, `config/mailerTransport.php`
   и другие из списка игнора).
2. Проверяйте синтаксис PHP перед коммитом: `php -l <файл>`.
3. После изменений на сервере делайте коммит и пуш, чтобы резерв на GitHub
   оставался актуальным.
4. Сообщения коммитов — коротко и по существу, на русском или английском.

Вопросы и предложения — через issues репозитория.
