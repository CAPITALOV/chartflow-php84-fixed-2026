# Security Policy

## Поддерживаемые версии

Актуальная ветка — `main`. Обновления безопасности выпускаются только в неё.

## Как сообщить об уязвимости

Пишите на адрес почты владельца репозитория — info@sotis.org

## Правила для участников

- **Никогда не публикуйте** в issues и pull request'ах пароли, токены,
  ключи API и содержимое файлов `config/db.php`, `config/mailerTransport.php`.
- Секреты храните только в игнорируемых файлах на рабочем сервере.
- Обнаружили утечку секрета — сразу смените его у провайдера (SMTP-панель,
  BotFather и т. п.), удаление из git-истории не заменяет ротацию пароля.
